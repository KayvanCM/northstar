# Archive

`forest-bricolage/` is the original Northstar visual identity (Bricolage Grotesque + Geist, forest green #0F3E17, mulberry accent), last edited 2026-10-23.

It was retired on 2026-11-03 when the project was consolidated into the parent folder. The parent carries everything this version had, plus the "Who's Running It" study section, the site contact and directions upgrades, Timeless Serif / Timeless Sans Grotesk fonts, the spruce and terracotta palette, and the compass-needle mark.

Nothing here is loaded by the live pages. To restore the old look, copy `forest-bricolage/assets/styles.css` over `../assets/styles.css`, swap the font `<link>` tags back, and use its `mark` icon in `assets/app.js`.
